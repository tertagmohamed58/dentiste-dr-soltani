# Instructions pour les photos réelles du cabinet / تعليمات الصور الحقيقية للعيادة

Placez vos photos réelles dans ce dossier avec les noms suivants pour qu'elles s'affichent automatiquement sur la Landing Page :
ضع صور العيادة الحقيقية داخل هذا المجلد بالأسماء التالية لتظهر تلقائيًا في الصفحة:

1. **Logo du cabinet / شعار العيادة**:
   - `logo.png` ou `logo.jpg`

2. **Photo de la Dre Soltani (Affiche SOLTANI DENTAL CLINIC) / صورة الطبيبة**:
   - `doctor-soltani.jpg`

3. **Services Vedettes / الخدمات المميزة**:
   - `service-implantologie.jpg` (Implantologie / زراعة الأسنان)
   - `service-orthodontie.jpg` (Orthodontie / تقويم الأسنان)
   - `service-esthetique.jpg` (Esthétique du sourire / تجميل الابتسامة)

4. **Résultats Avant / Après / النتائج قبل وبعد**:
   - `result-before.jpg` (Avant / قبل)
   - `result-after.jpg` (Après / بعد)

5. **Galerie du cabinet / معرض صور العيادة**:
   - `gallery-exterieur.jpg` (1. Extérieur du cabinet / الواجهة الخارجية: الجدار الرخامي مع شعار Soltani & Co والأريكة السوداء)
   - `gallery-salle-soins.jpg` (2. Salle de soins / قاعة العلاج: كرسي الأسنان، مصباح العلاج، الشاشة والأدوات)
   - `gallery-details.jpg` (3. Détails intérieurs / تفاصيل داخلية: دليل ألوان الأسنان VITA classical A1–D4)
   - `gallery-reception.jpg` (4. Réception / الاستقبال: الفاصل الخشبي والأريكة المنحنية)
   - `gallery-entree.jpg` (5. Entrée / المدخل: باقة الزهور)

> **Note**: Si une photo n'est pas encore ajoutée, la page affichera élégamment un cadre professionnel avec la mention :
> « Photo à venir » en français et « الصورة قريبًا » en arabe, conformément aux instructions déontologiques.
